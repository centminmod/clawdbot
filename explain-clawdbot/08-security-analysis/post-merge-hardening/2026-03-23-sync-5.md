#### Harden no-isolate timer and undici seams ([`1822db922`](https://github.com/openclaw/openclaw/commit/1822db9227))

This commit extracts undici's HTTP client dependencies (`Agent`, `EnvHttpProxyAgent`, `ProxyAgent`) into a lazy-loaded seam via `loadUndiciRuntimeDeps()` in the new file `src/infra/net/undici-runtime.ts`. The seam supports test overrides via the `TEST_UNDICI_RUNTIME_DEPS_KEY` constant, allowing test suites to inject mock HTTP stacks without interfering with production module loading or triggering cross-test pollution from globally mutated undici state.

The commit also hardens gateway-lock timing by making `now()` and `sleep()` injectable callbacks in `GatewayLockOptions`. This eliminates hard dependencies on `Date.now` and `setTimeout` globals that could be mutated by parallel no-isolate test suites, enabling deterministic security test coverage of time-sensitive lock acquisition logic.

In the context of Audit 2 Claim 4 (DNS rebinding SSRF via web-fetch), this commit improves the testability of the network layer rather than patching a direct SSRF vulnerability. The undici seam allows tests and auditors to reliably intercept HTTP client calls and verify SSRF guard behavior without depending on real network calls or fragile global timer state.

#### Ignore poisoned home env values ([`52b9d2091`](https://github.com/openclaw/openclaw/commit/52b9d2091e))

The `normalize()` function in `src/infra/home-dir.ts` now rejects the literal string values `"undefined"` and `"null"` as invalid `HOME` environment variable values, returning `undefined` to trigger safe fallback path resolution instead.

Without this guard, a misconfigured or attacker-controlled environment setting `HOME=undefined` or `HOME=null` would cause `path.resolve()` to expand `~` to a literal `undefined` or `null` subdirectory (e.g., `undefined/.openclaw/...`). This could break path traversal containment logic that assumes `HOME` resolves to an actual filesystem path.

This defense-in-depth control addresses the env variable injection surface from Audit 2 Claim 8. It does not close Legitimate Gap 1 (no `LD_*`/`DYLD_*` blocklist on the gateway side) but adds a concrete guard against poisoned string values that commonly appear in misconfigured CI or injected environments.

#### Escalation Review — Share Nested Account Config Merges ([`ff941b019`](https://github.com/openclaw/openclaw/commit/ff941b0193))

**Escalation verdict: Non-security.** This commit extracts shared account configuration merge helpers for IRC, Matrix, Mattermost, and Nextcloud Talk channel extensions, consolidating repeated config merge call patterns into a common helper and reducing boilerplate across extension `accounts.ts` files.

The escalation was triggered by keyword pattern matching on `credential`, `password`, and `secret` strings within account configuration handling files. Manual review confirmed these are configuration field names in existing data structures, not new or modified credential handling logic. No security controls were added, removed, or altered.
